# SprinkSense

SprinkSense is a smart irrigation companion app built with Flutter and Firebase. It connects to an Arduino-based soil moisture sensor and pump over Firebase Realtime Database, letting you monitor soil conditions, control watering manually or automatically, and review activity history - all from your phone or browser.

Live demo: https://smartirrigationsystem.netlify.app

## Features

- Authentication - email/password sign-up and login, plus Google Sign-In, backed by Firebase Auth.
- Live dashboard - real-time soil moisture readings streamed from an Arduino via Firebase Realtime Database.
- Manual and automatic pump control - toggle the pump directly, or set a moisture threshold and let the system water automatically.
- Activity history - a running log of pump events with a moisture trend chart (powered by fl_chart).
- Profile page - basic account info and sign-out.
- Cross-platform - runs on Android, iOS, web, Windows, macOS, and Linux from a single Flutter codebase.

## Tech stack

- App framework: Flutter (Dart)
- Auth: Firebase Authentication (email/password, Google)
- Data: Firebase Realtime Database
- Charts: fl_chart
- Hosting (web): Netlify, auto-deployed from main
- Hardware: Arduino + soil moisture sensor + relay/pump

## Project structure

lib/
- components/       Reusable widgets (buttons, text fields, theme constants)
- pages/
  - auth_page.dart          Routes to login/register or the main app based on auth state
  - login_page.dart         Email/password + Google sign-in
  - register_page.dart      Account creation + Google sign-in
  - login_or_register.dart  Toggles between login and register
  - main_page.dart          Bottom navigation shell
  - home_page.dart          Live sensor dashboard
  - control_page.dart       Manual/automatic pump control
  - activity_page.dart      History + moisture chart
  - profile_page.dart       User profile
  - database_service.dart   Firebase Realtime Database access layer
- firebase_options.dart       Generated by FlutterFire CLI
- main.dart                   App entry point

## Getting started

### Prerequisites

- Flutter SDK (Dart 3.6.1+)
- A Firebase project with Authentication (Email/Password and Google providers enabled) and Realtime Database set up
- The FlutterFire CLI if you're pointing this at your own Firebase project

### Run locally

    git clone https://github.com/Eliaskiplangat/sprinksense-smi.git
    cd sprinksense-smi/sprink_sense_smi
    flutter pub get
    flutter run

To run the web build specifically:

    flutter run -d chrome

### Using your own Firebase project

This repo ships with a working firebase_options.dart and google-services.json pointed at the original project's Firebase backend. To connect it to your own instead:

    flutterfire configure

This regenerates firebase_options.dart and the platform config files for your project. Make sure to also:

1. Enable Email/Password and Google under Authentication -> Sign-in method.
2. Add your deployed domain (e.g. your Netlify URL) under Authentication -> Settings -> Authorized domains.
3. Set up your Realtime Database with Arduino-Data, Control, and Activity nodes matching the structure expected in database_service.dart.

## Deployment

The web build auto-deploys to Netlify on every push to main, using the build configuration in netlify.toml (it clones the Flutter SDK on Netlify's build server and runs flutter build web --release).

## Hardware side

SprinkSense expects an Arduino (or similar microcontroller) that:

- Reads a soil moisture sensor and writes the value to Arduino-Data in Firebase Realtime Database.
- Listens for pump commands on the Control node and drives a relay/pump accordingly.
- Logs pump on/off events to the Activity node for the history view.
